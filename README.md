# Fashion MNIST Classifier

Train a CNN on the [Fashion MNIST](https://github.com/zalandoresearch/fashion-mnist) dataset with TensorFlow/Keras, then serve it through a FastAPI REST API with a simple drag-and-drop web page.

Upload a clothing image and the model predicts one of 10 classes:
T-shirt/top, Trouser, Pullover, Dress, Coat, Sandal, Shirt, Sneaker, Bag, Ankle boot.

## Features

- CNN trained with TensorFlow/Keras (expected test accuracy around 91-92%)
- REST API built with FastAPI (`/predict`, `/health`, auto docs at `/docs`)
- Web UI (`index.html`) with image upload, preview, and per-class probability bars
- Docker support for deployment
- Script to export sample test images

## Project structure

## Setup

```bash
git clone <your-repo-url>
cd <repo-folder>
python -m venv venv
venv\Scripts\activate        # Windows
# source venv/bin/activate   # macOS/Linux
pip install -r requirements.txt
```

## Usage

### 1. Train the model

```bash
python train.py
```

Downloads Fashion MNIST, trains for 10 epochs, prints test accuracy, and saves `model.keras`.

### 2. Run the app

```bash
python app.py
```

Open http://127.0.0.1:8000 in your browser.

Alternatively: `uvicorn app:app --reload`

### 3. Try it with sample images

```bash
python make_test_images.py
```

This creates a `test_images/` folder with 20 labelled PNGs. Upload them on the web page with **Invert unticked**.

## API

### `POST /predict`

Upload an image as multipart form data.

| Parameter | Type  | Description                                                     |
|-----------|-------|-----------------------------------------------------------------|
| `file`    | file  | Image to classify                                               |
| `invert`  | bool  | Query param. Use `true` for dark items on a light background    |

```bash
curl -X POST "http://127.0.0.1:8000/predict?invert=false" -F "file=@test_images/sneaker_1.png"
```

Example response:

```json
{
  "class": "Sneaker",
  "confidence": 0.9876,
  "probabilities": { "T-shirt/top": 0.0001, "Trouser": 0.0, "...": "..." }
}
```

### `GET /health`

Returns `{"status": "ok"}`.

## Docker

Train the model first so `model.keras` exists, then:

```bash
docker build -t fashion-mnist-api .
docker run -p 8000:8000 fashion-mnist-api
```

## Tips for good predictions

Fashion MNIST images are 28x28 grayscale with a **light item on a dark background**.

- Dataset images: leave **Invert** off.
- Your own photos: use a plain white background, crop tightly around the item, and turn **Invert** on.
- Real-world photos will usually score lower than the test set.
